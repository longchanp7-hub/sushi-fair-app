# ソウル3日間 旅ナビ

2026年8月28日〜30日のソウル旅行だけに使う、日本語専用の旅ナビです。

## 使う人

- AIやITに詳しくない人
- iPhone 17 Proを使用
- 韓国語を話さない人
- 旅行中は細かい設定をせず、表示されたボタンを押すだけで使いたい人

## 入っているもの

- 3日間の予定と完了チェック
- 正しい位置関係に直した簡易地図とAppleマップ連携
- 買い物・持ち物チェック
- 日本語で使う「困ったとき」案内
- Hugging Faceの文章判定を端末内で動かす補助機能
- 帰国便の逆算と、3日目の時間不足警告
- 警察・救急・観光案内・日本大使館への電話ボタン
- ホーム画面への追加と、基本画面のオフライン利用

## 大切な設計方針

- 予定は勝手に組み替えません。
- AIは自由に回答を作らず、確認済みの案内の中から近いものを選びます。
- 正確な予約先住所、便名、空港ターミナルは予約票・Eチケットを優先します。
- 3日目の眉アートと16:05発の便は時間がぶつかるため、警告を常時表示します。

## 技術

- HTML / CSS / JavaScript
- PWA、Service Worker、localStorage
- Apple Mapsの検索リンク
- Hugging Face Transformers.js
- `Xenova/paraphrase-multilingual-MiniLM-L12-v2`
- GitHub Pages

サーバーや有料APIキーは不要です。文章判定モデルは、本人が「旅行前に準備」を押したときだけ読み込みます。読み込めない場合も、基本の単語判定で案内を続けます。
