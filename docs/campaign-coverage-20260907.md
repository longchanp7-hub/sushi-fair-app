# 2026-09-07 公式告知の収録漏れ対策

対象: かっぱ寿司、にぎりの徳兵衛。既存8チェーンの品質ゲートとは独立した「公式一覧にある告知が最終データにも残っているか」の検査を追加する。

- `campaignCatalog` は主フェアの `items` / `campaigns` とは別に持つ。予告・持ち帰り・平日ランチ・優待の価格を、現在の店内寿司価格へ混在させない。
- 個別の2026年9月の告知を本番用固定配列にはせず、公式サイト/同社公式PR一覧から毎回発見する。
- 近日開始は45日先まで。期限切れは除外。期間不明は明示し、告知更新日を販売開始日に代用しない。
- HTML画像内など商品を抽出できない場合も、告知自体は保持し `itemStatus=unavailable` と表示する。告知収録を商品完全取得とは呼ばない。
- 公式一覧取得の成否、除外理由、期待URL集合を独立レポートに保存し、品質ゲート通過後の最終データと照合する。
- 通信失敗時の確認日時は更新しない。前回情報の自動保持は3日まで。未確認は未確認と表示する。
- 現段階で告知の網羅性確認を導入するのは2チェーンのみ。8チェーンすべての網羅性、自動ロールバック、画像内商品一覧の完全抽出は本変更の完了対象ではない。

## 確認方法

`node --test scripts/test-campaign-catalog.mjs`

`node scripts/campaign-catalog.mjs --report /tmp/campaign-coverage.json`

`node scripts/campaign-catalog.mjs --verify --report /tmp/campaign-coverage.json`

最終の公開後検証にも期待URL集合との照合を接続する。Actionsが緑でも全商品の正しさや在庫を保証しない。
