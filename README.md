# 寿司フェア

スシロー・はま寿司・くら寿司・かっぱ寿司・魚べいの期間限定フェアを、地域を選んで横断確認する個人向けPWAです。

## 全国版MVP

- GPSは使わず「都道府県 → 市区町村」を手動選択
- 選択地域は `localStorage` に保存
- 5チェーンの全国・公式フェアを横断表示
- チェーンごとのメニュー区分を別々に管理
  - スシロー: 店舗別メニュー・価格
  - はま寿司: 地域区分 + 都市型等の価格差
  - くら寿司: 店舗価格帯 + 商品提供エリア
  - かっぱ寿司: 店舗メニュータイプ
  - 魚べい: 通常 / 都心型 / 超都心型等の価格区分
- 店舗で未掲載・品切れになっても、それだけでは全国フェアを販売終了にしない
- `saleStatus`（販売状態）と `scrapeStatus`（取得状態）を分離
- 独自の混雑度算出は主要UIから外し、各社の公式店舗検索・予約・順番待ちへリンク

## 段階移行

既存のスクレイパーを一度に全面書き換えず、まず従来の安定した取得結果を入力として使い、その後 `scripts/build-national-fairs.mjs` で全国向け `schemaVersion: 2` に整形します。今後、チェーンごとに公式地域・店舗情報のresolverを強化できる構造です。

## 更新

GitHub Actionsで公式公開情報を毎日更新し、更新後の `app/` をGitHub Pagesへデプロイします。スクレイピングに失敗した場合は販売終了と断定せず、確認済みの情報を安全側に保持または警告表示します。
